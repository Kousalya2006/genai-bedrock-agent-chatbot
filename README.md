# Amazon Bedrock Agent Chatbot

## Overview
This project explores building a Generative AI chatbot using Amazon Bedrock and AWS services. It demonstrates how an AI assistant can retrieve relevant information and use agent-based workflows to help answer user questions.

## Technologies Used
- Python
- Amazon Bedrock
- Amazon S3
- AWS Lambda
- Amazon Athena
- Generative AI
- AI Agents
- Retrieval-Augmented Generation (RAG)

## Key Concepts
- **Generative AI:** Generate responses using foundation models.
- **Retrieval-Augmented Generation (RAG):** Retrieve relevant information to support responses.
- **AI Agents:** Use tools and multi-step workflows to address tasks.
- **AWS Services:** Explore cloud-based components for data storage and processing.

## Getting Started

2. Review the original project's documentation and prerequisites.
3. Configure the required AWS credentials securely.
